# Desktop Pet

A macOS desktop pet app built with Swift/AppKit. The pet stays above the Dock, walks left and right, reacts to hover with a teaser animation, and supports eating, sleeping, petting, scratching, and dragged poses.

The menu bar and right-click menus include mode switching plus size and opacity sliders. Appearance and mode settings are saved automatically and can be restored with `Reset Appearance`.

## Modes

- `Companion Mode`: normal walking, hover teaser, dragging, and playful automatic actions.
- `Work / Quiet Mode`: combines the old Quiet and Work behavior. The cat stays in the bottom-right corner and sleeps by default. Meal reminders trigger eating, while click wake-ups randomly trigger eating or scratching.

## Life Reminders

- Meal reminders at `08:00`, `12:30`, and `18:30`: the cat walks to a Dock edge and eats.
- Rest reminder every `50` minutes in Companion Mode: the cat lies down and sleeps.
- Idle reminder after `12` minutes without interaction in Companion Mode: the cat plays the petting interaction.

## Current Actions

- `walk`
- `walk_left`
- `teaser`
- `eat`
- `scratch`
- `drag`
- `sleep`
- `pet`

All runtime sprites are optimized transparent `384x384` PNG frame sequences under `assets/sprites`. GIF exports for quick review are under `assets/gifs`, but they are not bundled into the app unless `INCLUDE_GIF_PREVIEWS=1` is set during packaging.

## Build

```bash
env CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-module-cache" scripts/build_macos_app.sh
```

The script creates a signed local app bundle in `dist/`.

## Run

```bash
open dist/DesktopPet.app
```

If a timestamped app bundle was produced, open that bundle instead, for example:

```bash
open dist/DesktopPet-YYYYMMDDHHMMSS.app
```

## Asset Pipeline

The current video-derived sprites can be regenerated from `source_videos`:

```bash
python3 scripts/extract_video_sprites.py
python3 scripts/optimize_runtime_sprites.py
python3 scripts/make_motion_preview.py
python3 scripts/make_action_gifs.py
```

The generated report is written to `assets/video_sprite_report.json`, and the preview sheet is written to `assets/video_sprite_preview_contact_sheet.jpg`.

## Notes

- `walk_left` is generated by mirroring `walk`.
- Runtime sprites are downscaled to `384x384` to keep the app bundle and decode memory smaller.
- Build products, temporary frame extraction folders, and older image-generation intermediates are intentionally ignored by Git.
- The app uses a bounded per-frame image cache instead of loading every PNG at launch, which keeps memory usage lower with long video-derived animations.
